# Minha Agenda

Aplicação web de agenda mensal desenvolvida por **Pedro Batista** com HTML, CSS e JavaScript puro.

## Recursos

- calendário mensal com navegação e destaque do dia atual;
- cadastro, edição e exclusão de compromissos;
- categorias identificadas por cores;
- validação dos campos e horários;
- armazenamento dos dados no navegador;
- temas claro e escuro com preferência salva;
- interface responsiva para computador e celular.

## Como usar

Abra o arquivo `index.html` em um navegador. Não é necessário instalar dependências.

Os compromissos ficam salvos no `localStorage` do próprio navegador.
